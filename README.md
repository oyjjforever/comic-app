# Comic Reader 移动端

基于 Flutter 的漫画/视频阅读客户端，通过局域网连接电脑端 Comic Reader 服务器使用，支持手机、平板与 Android TV。

## 功能特性

### 连接

- 全自动连接：启动即连，优先直连上次的服务器，失败自动扫描局域网，全程无需手动输入地址

### 漫画

- 多数据源目录浏览，文件夹树懒加载
- 树顶"已收藏"分组，与电脑端实时同步；长按树节点即可收藏目录
- 收藏 / 浏览历史 / 下载历史，支持当前列表搜索
- 沉浸式阅读：翻页、双指缩放、进度条跳转、前后页预加载

### 视频

- 多数据源目录浏览
- 封面优先使用电脑端的缓存（支持自定义帧），卡片显示分辨率和时长
- 播放：倍速、快进快退、全屏、屏幕常亮

### 体验

- 深色主题，Material 3 设计
- 手机 / 平板 / TV 自适应布局，网格列数随屏幕宽度自动调整
- Android TV 遥控器完整支持：方向键导航、OK 键确认、阅读器与播放器按键操作

## 环境要求

- 电脑端运行 [Comic Reader](https://github.com/oyjjforever/comic-reader) 并与手机处于同一局域网
- 手机与电视安装 Android 7.0 以上版本

## 快速开始

```bash
flutter pub get
flutter run
```

打包：`flutter build apk --release`
